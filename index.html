An Introduction to Linked Lists

01

What is a linked list?

A linked list is a data structure that stores a sequence of data using nodes. Unlike an array, the elements are not stored next to each other in memory. Instead, each node contains a reference (or pointer) to the next node, forming a chain.

Head

The list itself is nothing but a pointer called "head," pointing at the first node. Lose that pointer and the whole list is unreachable, even though the nodes still exist in memory.

Null

The last node's "next" points at nothing — null. That's how traversal knows to stop. Forgetting to check for null is the single most common linked-list bug.

02

What is a node?

A node is the basic building block of a linked list. Each node contains two parts:

  1. Data (Value) — the information being stored.
  2. Next Pointer (Reference) — a link to the next node in the list.

A node stores a value and knows where the next node is. Connecting many nodes together creates a linked list.

03

Linked list vs. array

Both store an ordered collection of values. The biggest difference is how they store data in memory, and that affects how efficient different operations are.

Linked list
Array
Memory layout
Nodes can be stored anywhere in memory. Each node is connected to the next using a pointer.
Elements are stored in one continuous block of memory, one after another.
Accessing by index
O(n) Must walk from head, following pointers one node at a time.
O(1) Can jump directly to any index because the memory locations are contiguous.
Inserting / deleting
O(1) at a known position — simply update a few of pointers, nothing else moves.
O(n) Elements after the insertion or deletion point must shift to make room or fill the gap.
Sizing
Can grow or shrink one node at a time. There is no fixed capacity.
Often has a fixed capacity. If it becomes full, a larger array must be allocated and all elements copied over.
