01

What is a linked list?

A linked list is a chain of nodes. Each node holds a value and a pointer to the next node in the chain — that pointer is the only thing connecting one node to the next.

Head

The list itself is nothing but a pointer called "head," pointing at the first node. Lose that pointer and the whole list is unreachable, even though the nodes still exist in memory.

Null

The last node's "next" points at nothing — null. That's how traversal knows to stop. Forgetting to check for null is the single most common linked-list bug.

02

What is a node?

A node is a small package holding two things: a value, and a pointer to the next node — usually just called next. That's the entire unit. No size, no neighbors, no built-in position, just value + next.

03

Linked list vs. array

Both store an ordered collection of values, but the way they're laid out in memory changes what's cheap and what's expensive.

Linked list
Array
Memory layout
Nodes live wherever there's room, scattered around memory and connected only by pointers.
One contiguous block — every element sits right next to the last, back to back.
Accessing by index
O(n) Must walk from head, following pointers one node at a time.
O(1) Jump straight to any index using its memory offset.
Inserting / deleting
O(1) at a known position — rewire a couple of pointers, nothing else moves.
O(n) Every element after the gap has to shift over to close or open the space.
Sizing
Grows or shrinks freely, one node at a time — no wasted space, no upfront limit.
Often fixed-size, or the whole block gets reallocated and copied elsewhere to grow.
